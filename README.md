# Журнал успеваемости

Программа представляет собой простой журнал успеваемости студентов.

## Что есть в программе

Можно:

- добавлять баллы студентам;
- получать оценку по количеству баллов;
- считать средний балл студента;
- считать средний балл по дисциплине;
- считать средний балл группы;
- находить отличников;
- находить должников;
- получать ведомость по дисциплине на определённую дату.

## Оценки

Используется следующая система:

- 0-49 — неудовлетворительно;
- 50-69 — удовлетворительно;
- 70-89 — хорошо;
- 90-100 — отлично.

## Основные классы

`Student` — студент.

`Group` — группа студента.

`Discipline` — учебная дисциплина.

`GradeBookNumber` — номер зачётной книжки.

`Grade` — перечисление оценок.

`ControlPoint` — общая контрольная точка.

От него наследуются:

- `RegularControlPoint` — обычная контрольная;
- `ExamControlPoint` — экзамен.

`GradeEntry` хранит студента, контрольную точку и количество баллов.

`AcademicJournal` содержит основную работу с журналом.

## ООП

В проекте используется наследование и интерфейс.

`ControlPoint` реализует интерфейс `WeightedComponent`.

`RegularControlPoint` и `ExamControlPoint` наследуются от `ControlPoint`.

Также используется полиморфный метод `getType()`.

## Исключение

Если количество баллов меньше 0 или больше 100, выбрасывается собственное исключение:

`InvalidPointsException`.
